# business-strategist

A subagent that acts as a strict, honest business mentor: competitive analysis, market entry, business models, pricing, unit economics and growth plans, in simple words with real numbers. Adapted from "Business Strategist" in [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT).

## Use

Ask Claude: "Use the business-strategist agent to look at my idea: …" or type `@business-strategist`. Installed as a plugin, its name is `business-strategist:business-strategist`.

## Install

```
/plugin install business-strategist --marketplace apexledgerr-wq/claude-kit
```

Or by hand:

```bash
cp plugins/business-strategist/agents/business-strategist.md ~/.claude/agents/
```
